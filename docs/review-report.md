# Два незалежні перевіряльники

Перевірка виконана по всіх `app/`, `components/` і `lib/` файлах source-проєкту. Два проходи проводились окремо: 1) web-interface/accessibility/performance; 2) code/content slop і твердження без опори в переданому сайті.

## Перевіряльник 1 — інтерфейс, доступність, рух

**Результат: pass із виконаними виправленнями.**

- Додано skip link, глобальний видимий `:focus-visible`, справжні посилання для навігації, точні підписи CTA та `aria-live` для статусів — `components/Nav.tsx`, `components/Scanner.tsx`, `components/OpenStatus.tsx`.
- Рух узгоджено з `prefers-reduced-motion`; поле нерухоме за замовчуванням і рухається лише коротко у відповідь на курсор; воно зупиняється або малюється нерухомим кадром, відгуки мають кнопки попереднього/наступного та pause — `app/globals.css`, `components/FadeField.tsx`, `components/Reviews.tsx`.
- Усі імпортовані портрети мають `width`/`height`, реальні `sizes`, семантичний alt та не завантажуються у Hero — `components/Masters.tsx`.
- Вкладки цін працюють клавішами зі стрілками/Home/End, вибір рівня доступний у query string, фото приймаються лише у декодованих браузером JPG/PNG/WebP (до 15 МБ); у reduced-motion режимі очікування демо скорочене — `components/Prices.tsx`, `components/Scanner.tsx`.
- Додано реакцію pinned-галереї на клавіатурний фокус, щоб картка не лишалась за межами viewport — `components/Masters.tsx`.
- Ціни й дата формуються через `Intl`; числові значення лишаються числами й форматуються через `Intl.NumberFormat` — `lib/format.ts`, `components/Prices.tsx`.

**Обмеження перевірки:** не було браузерного рушія чи встановлених Next/Tailwind/Framer залежностей, тому не заявляю про візуальне E2E, accessibility tree у реальному браузері або production build. Перевірка була статичною й синтаксичною; тестом перевірено in-page anchors, імпорти й наявність локальних фото.

## Перевіряльник 2 — якість коду й опора на джерело

**Результат: pass; обмеження даних явно задокументовані.**

- У перевірених app-компонентах немає `console.log`, `as any`, поглинутих помилок, `TODO`/`FIXME`, фіктивних імпортів або прихованого persistence.
- Спільні форматери, токени руху, дані й media-query винесені в `lib/`; повторювана шкала майстрів і прайс не копіюються з різними джерелами.
- Дата snapshot прайсу й джерело збережені в `lib/data.ts`; маркетингову фразу про «три покоління» з вихідного концепт-документа прибрано, бо там вона позначена як текст, якого немає в системі запису.
- Demo-підбір прозоро названо бета-евристикою за пропорціями кадру; в інтерфейсі немає твердження, що це запущений ML/AI. Фото не пересилається й не зберігається.
- Altegio лишається єдиним місцем створення запису; в коді немає окремого неавторизованого запису/форми.

## Технічна перевірка

- Esbuild parse всіх TS/TSX файлів: **0 синтаксичних помилок**.
- Перевірено типи чистих data/format/motion утиліт; повний `tsc` для React-компонентів не запускався через відсутні типи Next/React/Framer Motion.
- Залежності проєкту, `npm run typecheck`, `npm run build`, браузерна перевірка й локальні сканери не запускалися: пакети відсутні в кеші, мережевого доступу в середовищі немає.
